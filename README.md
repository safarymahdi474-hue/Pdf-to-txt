# بات تلگرام OCR فارسی

این بات فایل PDF اسکن‌شده رو می‌گیره، با OCR متن فارسیش رو استخراج می‌کنه و به‌صورت فایل `.txt` برمی‌گردونه.

## نصب

### ۱. پکیج‌های سیستمی (Ubuntu/Debian)
```bash
sudo apt-get update
sudo apt-get install tesseract-ocr tesseract-ocr-fas poppler-utils
```
- `tesseract-ocr-fas` = دیتای زبان فارسی برای Tesseract (بدون این، OCR فارسی کار نمی‌کنه)
- `poppler-utils` = برای تبدیل PDF به عکس (pdf2image بهش نیاز داره)

روی سرورهای دیگه (مثلاً CentOS) اسم پکیج‌ها فرق می‌کنه؛ اگه سرورت رو بگی می‌تونم دستورشو بدم.

### ۲. پکیج‌های پایتون
```bash
pip install -r requirements.txt
```

### ۳. ساخت بات و گرفتن توکن
از [@BotFather](https://t.me/BotFather) تو تلگرام یه بات بساز و توکنش رو بگیر.

### ۴. اجرا
```bash
export BOT_TOKEN="توکن_شما"
python bot.py
```

## نحوه استفاده
فایل PDF اسکن‌شده رو به‌عنوان Document (نه عکس) به بات بفرست. بات مراحل رو گزارش می‌ده و در آخر فایل `.txt` رو برمی‌گردونه.

## پشتیبانی از فایل‌های حجیم (۵۰۰+ مگابایت)

نسخه فعلی برای همین حجم‌ها طراحی شده:
- PDF **دسته‌ای** (۱۰ صفحه در هر دسته) به عکس تبدیل می‌شه، نه یه‌جا — حافظه محدود می‌مونه
- هر دسته با چند پردازش موازی (`OCR_WORKERS`) OCR می‌شه
- متن هر دسته بلافاصله رو دیسک نوشته می‌شه — اگه یه‌جا کرش کرد یا قطع شد، نتیجه تا اون لحظه از دست نمی‌ره

### الزامی: راه‌اندازی Bot API سرور محلی

API ابری تلگرام دانلود فایل توسط بات رو به **۲۰ مگابایت** محدود می‌کنه. برای ۵۰۰ مگابایت باید Bot API سرور محلی (self-hosted) راه بندازی که سقفش **۲ گیگابایت** هست.

۱. از https://my.telegram.org یه `api_id` و `api_hash` بگیر (رایگانه، با شماره تلفنت لاگین می‌کنی)

۲. سرور محلی رو با Docker بالا بیار:
```bash
docker run -d --name telegram-bot-api \
  -p 8081:8081 \
  -e TELEGRAM_API_ID=<api_id> \
  -e TELEGRAM_API_HASH=<api_hash> \
  -v /var/lib/telegram-bot-api:/var/lib/telegram-bot-api \
  --restart always \
  aiogram/telegram-bot-api:latest
```

۳. موقع اجرای بات، آدرس این سرور رو بده:
```bash
export BOT_TOKEN="توکن_شما"
export LOCAL_API_BASE_URL="http://localhost:8081/bot"
export LOCAL_API_BASE_FILE_URL="http://localhost:8081/file/bot"
python bot.py
```

### نکات عملکردی برای فایل‌های خیلی حجیم
- `CONVERT_DPI` رو رو ۲۰۰ گذاشتم (به‌جای ۳۰۰) تا سرعت و حافظه بهتر بشه؛ اگه کیفیت اسکن پایینه و OCR دقیق نیست، بالاش ببر ولی حافظه بیشتر مصرف می‌کنه.
- `OCR_WORKERS` رو متناسب با تعداد هسته CPU سرورت تنظیم کن — بیشتر یعنی سریع‌تر ولی مصرف CPU/RAM بالاتر.
- فضای دیسک کافی برای فایل موقت PDF + عکس‌های هر دسته لازمه؛ حداقل ۲-۳ برابر حجم فایل ورودی رو خالی نگه دار.
- برای یه PDF چند هزار صفحه‌ای، پردازش کامل می‌تونه از چند ده دقیقه تا چند ساعت طول بکشه بسته به قدرت سرور — پیام وضعیت هر ۵۰ صفحه آپدیت می‌شه تا بدونی کجاست.
- اگه چند نفر هم‌زمان فایل حجیم می‌فرستن، بهتره یه صف کار (Celery + Redis) اضافه کنیم تا فایل‌ها همزمان کل CPU رو قاپ نزنن؛ اگه لازم شد بگو تا اضافه کنم.

## دیپلوی
این بات با polling کار می‌کنه، پس روی هر سروری (VPS، Railway، Render و ...) که پایتون و پکیج‌های سیستمی رو ساپورت کنه قابل اجراست. اگه بخوای با webhook یا روی پلتفرم خاصی دیپلویش کنیم بگو.
