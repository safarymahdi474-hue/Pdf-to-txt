# بات تلگرام OCR فارسی (نسخه لینک دانلود)

کاربر به‌جای آپلود مستقیم فایل، **لینک دانلود PDF** رو به بات می‌فرسته (مثلاً لینک اشتراک‌گذاری Google Drive یا هر لینک مستقیم دیگه). بات خودش با یه درخواست HTTP فایل رو دانلود می‌کنه، OCR فارسی روش اجرا می‌کنه و متن رو به‌صورت `.txt` برمی‌گردونه.

**چرا این‌طوری بهتره؟** فایل هیچ‌وقت از سرورهای تلگرام رد نمی‌شه، پس محدودیت ۲۰ مگابایتی API تلگرام برای بات‌ها اصلاً وارد بازی نمی‌شه — نیازی به Bot API سرور محلی، `api_id`/`api_hash`، Docker، یا Volume نیست.

## نصب روی VPS (Ubuntu)

### ۱. پکیج‌های سیستمی
```bash
sudo apt-get update
sudo apt-get install -y python3 python3-pip tesseract-ocr tesseract-ocr-fas poppler-utils
```

### ۲. کپی فایل‌ها رو سرور
فایل‌های `bot.py` و `requirements.txt` رو (مثلاً با `scp` یا کپی-پیست) رو سرور بذار.

### ۳. نصب پکیج‌های پایتون
```bash
pip3 install -r requirements.txt
```

### ۴. اجرا
```bash
export BOT_TOKEN="توکن_بات_شما"
python3 bot.py
```

### ۵. اجرای دائمی (بعد از بسته شدن SSH هم بمونه روشن)
ساده‌ترین راه استفاده از `screen` یا `tmux`:
```bash
sudo apt-get install -y screen
screen -S ocrbot
export BOT_TOKEN="توکن_بات_شما"
python3 bot.py
# بعد Ctrl+A و بعد D بزن تا از screen خارج بشی بدون اینکه بات متوقف بشه
```
برای برگشتن بهش بعداً: `screen -r ocrbot`

راه حرفه‌ای‌تر (توصیه می‌شه): اجرا به‌عنوان یه سرویس systemd، تا با ری‌استارت سرور هم خودش بالا بیاد. اگه خواستی این‌کارو هم بگو تا فایل سرویسش رو بسازم.

## نحوه استفاده
کاربر یه پیام متنی حاوی لینک PDF می‌فرسته (نه خود فایل). بات مراحل دانلود و OCR رو گزارش می‌ده و در آخر فایل `.txt` رو برمی‌گردونه.

### نکته درباره لینک Google Drive
لینک باید به‌صورت **اشتراک‌گذاری عمومی** (Anyone with the link) باشه، وگرنه بات نمی‌تونه دانلودش کنه. کد به‌صورت خودکار لینک‌های `drive.google.com/file/d/...` رو تشخیص می‌ده و به فرمت دانلود مستقیم تبدیل می‌کنه.

## نکات عملکردی
- `CONVERT_DPI` (پیش‌فرض ۲۰۰) و `OCR_WORKERS` (بر اساس تعداد هسته CPU) رو می‌تونی تو `bot.py` تنظیم کنی.
- `MAX_DOWNLOAD_BYTES` سقف ۲ گیگابایت گذاشته شده؛ اگه لازم شد بیشترش کن.
- برای فایل‌های چند صدصفحه‌ای، کل فرآیند (دانلود + OCR) می‌تونه از چند ده دقیقه تا چند ساعت طول بکشه بسته به قدرت VPS.
- اگه چند کاربر هم‌زمان فایل بفرستن، بهتره بعداً یه صف کار (Celery+Redis) اضافه کنیم تا هم‌زمان کل CPU رو قاپ نزنن.
